# Iniciando Projeto

## API

bundle install
bundle exec ruby api.rb 

## APP

- Entre na pasta carteira_digital_escolar
- Com o flutter instalado
    - flutter --version
    - Flutter 3.44.9


### Emulador Android (Recomendado)

- **Alterar a url no app_url.dart para urlEmulator**
- flutter pub get
- Escolher um android 13+


### Aplicativo rodando no chrome


- **Alterar a url no app_url.dart para url web**
- flutter pub get
- flutter run -d chrome
